📊 Customer Churn Analysis Using Exploratory Data Analysis (EDA)
📌 Project Overview

This project focuses on analyzing customer churn behavior in a telecom company using Exploratory Data Analysis (EDA). Customer churn refers to customers discontinuing telecom services, which can negatively impact company revenue and customer retention.

The objective of this project is to identify the major factors contributing to customer churn and generate meaningful business insights that can help improve customer retention strategies.

🎯 Problem Statement

Telecom companies face significant challenges in retaining customers in a highly competitive market. Customer churn can lead to major revenue loss and increased customer acquisition costs.

This project aims to analyze customer data to identify the major factors contributing to customer churn and understand customer behavior patterns using Exploratory Data Analysis (EDA).

🚀 Project Objectives
Analyze customer behavior patterns related to churn
Identify the major factors contributing to customer churn
Perform data cleaning and exploratory data analysis
Visualize relationships between customer attributes and churn
Generate business insights and recommendations

📈 Key Insights
Customers with month-to-month contracts showed higher churn rates.
Customers with shorter tenure were more likely to churn.
Higher monthly charges were associated with increased churn probability.
Customers without Tech Support and Online Security services showed higher churn behavior.
Electronic check payment users had relatively higher churn rates.
💡 Business Recommendations
Give special discounts or offers to customers who choose long-term contracts.
Pay more attention to new customers with lower tenure.
Encourage customers to use Tech Support and Online Security services.
Provide personalized offers to high-risk customers.
Improve customer support service and complaint resolution processes.
✅ Conclusion

This project successfully analyzed customer churn behavior using Exploratory Data Analysis techniques. The analysis identified several important factors influencing churn, including contract type, tenure, monthly charges, payment methods, and support services.

The insights generated from this analysis can help telecom companies make data-driven decisions to improve customer retention, reduce churn rates, and enhance overall customer satisfaction.
